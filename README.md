# Assignment 1: Basic Python Concepts

This repository includes two Python scripts completed as part of **Module 2: Basic Python Concepts**.

## Task 1: Basic Mathematical Operations
- This script asks the user to enter two numbers.
- It performs the following operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- The result of each operation is displayed to the user.

## Task 2: Personalized Greeting
- This script takes the user's first name and last name as input.
- It combines them into a full name.
- Then, it prints a personalized greeting message using the full name.
